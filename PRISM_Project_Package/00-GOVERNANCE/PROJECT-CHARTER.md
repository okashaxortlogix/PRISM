# PRISM — Project Charter
## Purpose
PRISM is an evidence-driven engineering investigation platform intended to help engineers understand software failures, investigate causes, test hypotheses, verify conclusions, assess impact, and produce traceable recommendations.

## Core principle
PRISM must never present an unsupported guess as a verified root cause. Evidence, provenance, confidence, contradictions, experiments, and verification are first-class concepts.

## V1 boundary
V1 focuses on software/project investigations. Autonomous uncontrolled production modification, deployment, or continuous autonomous guardian behavior are outside the initial release boundary.

## Quality bar
A launch candidate must be secure, observable, reproducible, explainable, testable, cost-controlled, and operationally supportable.

# PRISM — Product Vision
PRISM should turn a vague engineering problem into a structured investigation.

### The loop
Problem → Scope → Project understanding → Evidence → Hypotheses → Tests → Verification → Root cause → Impact → Recommendation → Record → Memory.

### Differentiation
The product should distinguish between:
- what is observed,
- what is inferred,
- what is hypothesized,
- what was tested,
- what was verified,
- and what remains unknown.

The product wins on investigation quality and traceability, not merely on chat quality.

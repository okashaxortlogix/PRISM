# PRISM — CI/CD
Pipeline:
1. Formatting/linting
2. Unit tests
3. Integration tests
4. Type/static checks
5. Dependency/security scanning
6. Build
7. Migration validation
8. Container/image scan
9. Deploy to staging
10. E2E/smoke tests
11. Manual release approval where required
12. Production deployment
13. Post-deploy health checks
14. Rollback if health criteria fail

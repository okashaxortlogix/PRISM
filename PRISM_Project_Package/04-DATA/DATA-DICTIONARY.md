# PRISM — Data Dictionary
All identifiers use stable opaque IDs. Timestamps are stored in UTC. Human-facing formatting occurs at the presentation layer.

### Evidence.reliability
A bounded value or categorical assessment representing how trustworthy the evidence source is.

### Evidence.provenance
Structured information describing where evidence came from and how it was collected.

### Hypothesis.confidence
A model/system assessment, not proof. Confidence must never override contradictory evidence.

### Verification.outcome
One of VERIFIED, REFUTED, INCONCLUSIVE, BLOCKED, FAILED.

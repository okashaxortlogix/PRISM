# PRISM — Launch Checklist
## Product
- [ ] V1 scope frozen
- [ ] Core workflows usable
- [ ] Onboarding complete

## Engineering
- [ ] CI/CD stable
- [ ] Database migrations tested
- [ ] Rollback tested

## Security
- [ ] Threat model reviewed
- [ ] Red-team completed
- [ ] Critical findings closed

## AI
- [ ] Golden benchmark passes
- [ ] Regression evaluation passes
- [ ] Unsupported-claim safeguards pass

## SRE
- [ ] Monitoring active
- [ ] Alerts tested
- [ ] Backup restore tested
- [ ] Incident runbooks ready

## Privacy/legal
- [ ] Privacy documentation reviewed
- [ ] Terms and required notices ready
- [ ] Data retention/deletion behavior verified

## Operations
- [ ] Support process ready
- [ ] Escalation defined
- [ ] Status communication ready

## Decision
Launch only if every critical gate is green.

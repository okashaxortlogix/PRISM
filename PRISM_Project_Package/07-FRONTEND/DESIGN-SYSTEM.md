# PRISM — UI/UX Design System
The interface should feel like a serious engineering investigation tool, not a generic AI SaaS dashboard.

Priorities:
- Clear information hierarchy
- Evidence visibility
- Investigation timeline
- Hypothesis comparison
- Explicit uncertainty
- Minimal decorative UI
- Accessible contrast and keyboard navigation
- Useful empty/loading/error/blocked states

Core screens:
Dashboard, Projects, Investigation Workspace, Evidence, Hypotheses, Experiments, Root Cause, Impact, Recommendations, Verification, Report, Settings.

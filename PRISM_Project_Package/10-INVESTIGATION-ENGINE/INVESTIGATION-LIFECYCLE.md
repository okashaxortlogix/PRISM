# PRISM — Investigation Lifecycle
1. Capture problem.
2. Define scope and constraints.
3. Identify project context.
4. Ingest relevant artifacts.
5. Collect evidence.
6. Normalize and link evidence.
7. Generate competing hypotheses.
8. Rank hypotheses against evidence.
9. Identify missing/contradictory evidence.
10. Design safe tests.
11. Run/observe tests.
12. Verify results.
13. Establish root cause or mark inconclusive.
14. Assess impact.
15. Compare solutions.
16. Produce recommendation.
17. Record decision and supporting evidence.
18. Store reusable memory with freshness metadata.

# PRISM — Master Implementation Package

This package is the implementation blueprint for PRISM.

## Recommended execution order
1. Read `00-GOVERNANCE`
2. Freeze `01-PRODUCT` and `02-REQUIREMENTS`
3. Approve `03-ARCHITECTURE` and `04-DATA`
4. Implement phases in `19-IMPLEMENTATION-PHASES` sequentially
5. Apply security, QA, SRE, FinOps, privacy, and localization controls continuously
6. Use `20-BENCHMARKS-EVALUATION` before changing AI behavior
7. Use `21-RELEASE-LAUNCH` as the final launch gate

## Important
This is a planning/implementation specification package, not a claim that the complete production software has already been implemented. Technology choices, exact APIs, hosting, model providers, and legal jurisdictions should be finalized during the architecture and discovery phases.

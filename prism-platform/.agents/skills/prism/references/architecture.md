# PRISM Reference Architecture

```text
User Problem
→ Investigation Orchestrator
→ Project Understanding
→ Hypothesis Generation
→ Evidence Collection
→ Evidence Validation
→ Experiment/Reproduction
→ Contradiction Engine
→ Root Cause Engine
→ Impact Analyzer
→ Decision/Solution Engine
→ Verification Engine
→ Investigation Record
→ Memory
```

Supporting layers:

- Authentication / RBAC / tenant isolation
- Database and migrations
- Queue and workers
- Repository ingestion
- AST/code intelligence
- LLM gateway
- Verification sandbox
- Integrations
- Observability
- FinOps
- Security/privacy
- Localization
- Reporting

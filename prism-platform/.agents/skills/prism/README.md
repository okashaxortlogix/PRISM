# PRISM Skill Package

PRISM is an evidence-first technical investigation skill for Antigravity.

## Files

- `PRISM-SKILL.md` — primary skill definition
- `references/` — canonical models and architecture
- `workflows/` — reusable investigation workflows
- `checklists/` — security, production, and false-completion checks
- `templates/` — reusable report templates
- `examples/` — small usage example

## Core idea

> Don't just tell me what's wrong. Prove it.

## Recommended use

Use `PRISM-SKILL.md` as the skill's primary instruction file. Keep the supporting files available to the skill as reference material.

## Scope

This package captures the PRISM methodology and acceptance standards. It does not replace project-specific requirements, security policies, or deployment controls.

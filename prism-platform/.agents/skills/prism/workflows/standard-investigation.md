# PRISM Standard Investigation Workflow

1. Scope the problem.
2. Establish expected vs observed behavior.
3. Understand the relevant project area.
4. Gather evidence.
5. Generate competing hypotheses.
6. Define falsification conditions.
7. Run the cheapest reliable verification first.
8. Record contradictions.
9. Synthesize the root cause.
10. Assess impact/blast radius.
11. Compare remediation options and trade-offs.
12. Recommend an action.
13. Verify the result.
14. Record unknowns and create the investigation record.

Never skip directly from symptom to root cause.

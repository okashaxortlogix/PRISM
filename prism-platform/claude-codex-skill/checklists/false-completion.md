# PRISM False-Completion Checklist

Search production code for:

- [ ] TODO
- [ ] FIXME
- [ ] XXX
- [ ] STUB
- [ ] MOCK
- [ ] SIMULATED
- [ ] PLACEHOLDER
- [ ] TEMP
- [ ] NOT_IMPLEMENTED
- [ ] COMING SOON
- [ ] fake
- [ ] hardcoded
- [ ] unused
- [ ] dead
- [ ] suspicious Math.random usage

Every finding must be classified as legitimate, test-only, or a real gap.
